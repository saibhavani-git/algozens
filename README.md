
# Algozens 🧠💡

Algozens is a full-stack web application for practicing and managing DSA (Data Structures & Algorithms) questions. It supports user registration, categorized problem browsing, and a clean interface to work through coding problems.

---

## 🚀 Features

- 🧑‍💻 User Registration and Authentication
- 🗂️ DSA Questions categorized by topic
- 📄 Flash messages and error handling
- 🧱 Modular file structure
- 🔐 Middleware for protected routes
- 🖼️ EJS templates for dynamic views
- 🎨 Custom styles using CSS

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS
- **Database:** MongoDB with Mongoose
- **Other Tools:** npm, Git, GitHub
